## 0. 读法：图片放进去就生效，不需要改代码

本模组所有卡牌卡图都通过 `ModAssetPathResolver.ResolveCardPortrait(GetType().Name, 模板图)` 解析：

1. **约定路径**：`GuZhenRenRubild/images/cards/<卡牌类名>.png`
2. 该文件**存在** → 用专属卡图；
3. 该文件**缺失** → 自动回退到模板图（攻击向 `GuZhenRenRubildStrike.png` / 防御向 `GuZhenRenRubildDefend.png`），不会把不存在的路径交给引擎。

因此**只要把下表里的 PNG 按「约定路径」放进目录、重新导出 PCK 即可换图**，无需修改任何 `.cs` 文件
（`export_presets.cfg` 使用 `export_filter="all_resources"`，新图会被自动打包）。

- 命名：**必须与类名完全一致**（区分大小写），扩展名小写 `.png`
- 格式：PNG，4:3 比例（现有素材的两种实际尺寸：模板图 `1000×760`、旧模组卡图 `512×384`）
- 状态说明：**缺失** = 当前没有专属图、正在复用模板图；**已有** = 专属图已入库并随 PCK 打包

## 7. 补图后的验证步骤

1. 把 PNG 放进 `GuZhenRenRubild/images/cards/`（图标放 `images/powers/`、`images/enchantments/`），文件名 = 类名。
2. 删除旧的 `.godot/imported/<文件名>*.md5` 之类的过期导入缓存（如 Godot 未自动重新导入）。
3. 纯编译校验 +（改过资源目录时）不部署导出校验：
   ```powershell
   dotnet build GuZhenRenRubild.csproj -p:CopyModOnBuild=false -p:RunPckExport=false -p:RitsuLibAutoCopy=false
   & <GodotExe> --headless --path . --export-pack "Windows Desktop" "artifacts\check.pck"
   ```
   再核对 PCK 是否收录：`Select-String -Path artifacts\check.pck -Pattern "images/cards/<类名>.png" -Encoding utf8`
   （`export_presets.cfg` 为 `all_resources`，新图会被自动打进 PCK）
4. 进游戏核对：卡牌奖励 / 蛊方大全「卡虫大全」「卡牌大全」页签 / 战斗卡面。
5. 若某张图**没有**生效，先确认文件名与类名逐字符一致（含大小写），再确认 PCK 里是否包含该文件。
